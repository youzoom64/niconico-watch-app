タイムシフトGUI・ローカル処理 取扱説明書

「Niconico タイムシフト / ローカル処理」は、放送URLから動画とコメントを取得したり、PCに保存済みの動画から文字起こし・分析・HTML生成・再公開を行ったりする専用画面です。監視アプリとは別プロセスで動くため、保存済み放送のやり直しにも使えます。

起動と画面構成 目的から選ぶ URLから取得 ローカル動画を処理 Stepの選び方 スペシャル処理 タグ修正 未アップロード 消滅URL登録 結果とエラー

1. 起動と画面構成

通常はプロジェクト内のscripts\start_timeshift_gui.cmdをダブルクリックして起動します。メインGUIから「ローカル処理へ送る」などを実行した場合も、この画面が開きます。既に起動していれば同じ画面へ追加されます。

タイムシフトGUIは一つだけ起動します。URL取得とローカル処理を同時に走らせず、同じ画面内で順番に処理します。

タブ何をする場所かよく使う場面
URLから取得放送URLや配信者の番組一覧URLから、タイムシフト動画とコメントを取得します。PCに動画がない放送を処理したい
ローカル処理PCにある動画を使い、必要なStepだけを実行します。文字起こし、HTML再生成、再公開
タグ修正保存済み放送のタグを編集し、HTMLと一覧を更新します。人物タグや分類を直したい
スペシャル処理スペシャルユーザーの一覧・個別HTMLを生成します。未生成ページの作成、AI分析、再公開
未アップロード生成済みでまだ公開されていない放送を選んで送信します。生成は終わったが公開だけ失敗した
消滅URL登録削除された放送を確認し、一覧へ反映します。公開一覧に削除済み放送の状態を反映したい

2. やりたいことから操作を選ぶ

動画がまだない「URLから取得」で放送URLを入力します。
PCに動画がある「ローカル処理」へ動画を追加します。
HTMLだけ作り直したいローカル処理でStep12・13・14を選びます。
公開だけやり直したいStep15、または「未アップロード」を使います。
スペシャルユーザーHTML「スペシャル処理」で対象行を処理します。
タグだけ直したい「タグ修正」で保存・再生成します。
動画がない ──→ URLから取得 ──→ 動画・コメント保存 ──→ 必要ならHTML生成 動画がある ──→ ローカル処理 ──→ 実行Stepを選択 ──→ 生成・再生成・公開 特殊な再処理 ──→ タグ修正 / スペシャル処理 / 未アップロード

3. URLからタイムシフトを取得する

  1. 「URLから取得」タブを開きます。
  2. 入力欄へ、放送URLまたは配信者の番組一覧URLを1行に1件入力します。
  3. HTMLまで作る場合は、実行するStepを選択します。
  4. 取得だけなら「動画・コメントのみ取得」を押します。
  5. 取得後にHTML生成まで続けるなら「動画・コメントを取得してHTML作成」を押します。
  6. 下部の処理状況で、URL解析、視聴可否、取得、コメント保存、生成結果を確認します。

入力例

https://live.nicovideo.jp/watch/lv350000000 https://www.nicovideo.jp/user/12345678/live_programs
  • 既に取得済みの動画があれば再利用します。
  • ライブ録画中の同じ放送は重複取得せず、録画終了を待ちます。
  • タイムシフト視聴期限切れ、非公開、権限不足の場合は取得できません。
  • コメントは保存済み件数を確認し、不足している場合にAPI取得します。

4. PCにある動画をローカル処理する

  1. 「ローカル処理」タブを開きます。
  2. 動画を一覧へドラッグ＆ドロップするか、「動画を追加」を押します。
  3. 一覧にLV番号とファイルパスが表示されたことを確認します。
  4. 実行するStepだけをチェックします。
  5. Step15を使う場合は、「MP3をアップロード」「スクショをアップロード」も確認します。
  6. 「ローカル動画からHTML作成」を押します。
  7. 下部の処理状況で、現在の工程と完了結果を確認します。

対応する動画

MP4、MKV、WebM、FLV、TSに対応します。ファイル名にはlvから始まる放送IDが必要です。

使用できる例: lv350000000_配信タイトル.mp4 録画_lv350000000_part2.mkv 使用できない例: 配信タイトル.mp4 ← lv番号がない

動画が分割されている場合

同じLV番号を持つ複数動画は一つの放送として扱います。録画区間DBがある場合は、その区間情報を使って時間軸を統合します。複数のLVを追加した場合は、放送日時が古い順に処理します。

Step01またはStep02を含む処理が成功すると、使用した元動画は生成HTMLと同じフォルダーのarchiveサブフォルダーへ移動します。元の場所に残したい場合は、Step01・02を外して後続Stepだけを実行してください。

5. Stepの選び方

チェックしたStepだけを実行します。ただしStep01・02を選ぶと、動画区間確認、音声抽出、文字起こしなどの前処理も行います。Step01・02を外すと、保存済みDB・音声・画像などを再利用して後続処理だけを行います。

目的選択するStep結果

HTML更新＋公開12・13・14・15再生成後、設定済みサーバーへ送信
タグ・一覧だけ更新13・14。公開するなら15配信者一覧とタグページを更新

最初から処理01から必要な最終Stepまで動画とコメントから一連の生成処理を実行

6. スペシャルユーザーHTMLを処理する

メインGUIのスペシャルユーザー確認画面から未処理放送を送ると、「スペシャル処理」タブへ対象が追加されます。通常のStep一覧とは別の処理です。

  1. 一覧で処理する行を選択します。「全選択」「全解除」も使えます。
  2. コメント表と基本統計にAI分析も加える場合は「AI分析を作る」をONにします。
  3. 既存の個別HTMLも上書きする場合だけ「既存HTMLを作り直す」をONにします。
  4. 生成後に公開する場合は「サーバーへアップロードする」をONにします。
  5. 「選択を処理」を押します。
設定動作
AI分析を作るONならAI分析を追加します。OFFならコメント表と基本統計だけなので速く処理できます。
既存HTMLを作り直すOFFなら作成済み個別HTMLを保持します。ONなら現在の設定で上書きします。
サーバーへアップロードする生成に成功したページを続けて公開します。

7. タグを修正する

保存済み放送のタグだけを修正したい場合は「タグ修正」タブを使います。対象LVを読み込み、タグを変更して保存すると、Step12・13・14を使って放送HTML、タグページ、配信者一覧を更新します。公開も選んだ場合はStep15まで実行します。

文字起こしや要約を作り直す必要はありません。タグ修正後は、個別HTMLだけでなく配信者一覧とタグ別一覧も確認してください。

8. 未アップロードの放送を公開する

HTML生成は成功したがStep15が失敗した場合や、後からまとめて公開する場合は「未アップロード」タブを使います。

  1. 一覧を更新し、未アップロードの放送を表示します。
  2. 公開する行を選択します。
  3. MP3やスクリーンショットも必要か確認します。
  4. アップロードを実行します。
  5. 完了後、公開URLで一覧、個別HTML、画像、タグページを確認します。

認証情報やAPIキーをログ、README、GitHub、生成HTMLへ書かないでください。

9. 消滅URLを一覧へ反映する

「消滅URL登録」は、既に生成済みの放送がニコニコ側で削除されているか確認し、その状態を公開一覧へ反映するための機能です。配信者を指定して確認すると、生成済みLVの実URLを調べ、削除済みの放送を記録します。変更があった場合は一覧関連Stepを再実行します。

10. 処理状況とエラーの見方

下部の処理状況には、LVごとの進行が順番に表示されます。

  • コメントをDBから再利用したか、APIから取得したか
  • 実行するStepとスキップするStep
  • 動画区間、音声抽出、文字起こしなど、現在開始した工程
  • HTML、MP3、動画アーカイブの生成先
  • 成功件数、失敗件数、失敗理由
表示・エラー確認すること
除外（lv番号なし）動画ファイル名へlv123456789形式の放送IDを入れます。
ローカル動画が見つからない対象動画を「ローカル処理」へ直接追加します。
実行するStepが選択されていない目的に必要なStepを一つ以上チェックします。
タイムシフト視聴不可視聴期限、公開状態、ログイン状態を確認します。
文字起こし失敗GPUメモリ、CUDA、モデル、動画・音声ファイルを確認します。
アップロード失敗公開先設定、認証、ネットワークを確認し、「未アップロード」から再実行します。

成功したLVは処理一覧から取り除かれます。失敗したLVは残るため、エラーを直した後に同じ対象を再実行できます。

タイムシフトGUIを閉じると、このGUIが開始した実行中の処理も停止します。処理中は完了表示が出るまで画面を閉じないでください。
